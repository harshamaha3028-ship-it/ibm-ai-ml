📐 High-Level System Architecture

End-to-End Pipeline

The system addresses two complementary machine learning challenges: predicting continuous fuel economy (Miles Per Gallon) through supervised regularized regression, and discovering vehicle class archetypes through unsupervised geometric clustering.

Vehicle Specs (Cylinders, Displacement, HP, Weight, Acceleration, Year, Origin)
    │
    ├──► [Preprocess & Feature Engineering] ──► [Regularized Regression (Ridge/Lasso)] ──► Predicted MPG
    │
    ├──► [StandardScaler + 2D PCA] ──► [KMeans Clustering (k=3)] ──► Vehicle Archetype Profile
    │
    └──► [Explainability Engine + Database Persistence] ──► Dashboard & Audit Trail

🏎️ Supervised Regression

R² ≈ 0.875

To ensure reliable generalization and mitigate collinearity between engine displacement, cylinder count, and vehicle mass, four regression formulations are benchmarked using 5-Fold Cross Validation:

  • Linear Regression (OLS): Baseline unpenalized ordinary least squares.
  • Ridge Regression (L2): Penalizes $||w||_2^2$ to shrink correlated coefficients and stabilize variance.
  • Lasso Regression (L1): Enforces sparsity via $||w||_1$ penalty for feature selection.
  • ElasticNet: Convex combination of L1 and L2 penalties ($L_{net} = r L_1 + (1-r) L_2$).

🏷️ Vehicle Profiling / Clustering

KMeans + PCA

Vehicles are segmented based on their multidimensional physical and efficiency footprint:

  • Optimal Cluster Selection: Confirmed via Elbow Curve (Inertia minimization) and Silhouette Analysis.
  • 2D PCA Projection: Preserves ~91.8% of feature variance for interactive scatter map visual inspection.
  • Dynamic Archetype Derivation: Labels are dynamically assigned from cluster centroid statistics compared to dataset medians.
